### What was wrong, structurally

The merged matrix had **three physics levels in columns that get counted against each other**:
42 rows Tier-0 Fick (no migration at all), 8 rows full Nernst-Planck + migration + EC', and one
of those 8 silently dropped back to Tier-0 when it failed to converge. "N of 50 clear 25" was
tallied across all three.

### What changed in the solver

| change | why |
|---|---|
| **Analytic Jacobian** (`jacobian_ec!`) | the finite-difference one left the deep-total-catalysis cells unconvergeable at any tolerance -- forward AND central differences both stall at residual 14, so it was conditioning, not precision. **Verified against central differences to 4.5e-8 worst case over 32 production states** (`jacobian_check`, 8 systems x 2 archetypes x 2 currents). VERIFY IT, do not trust it -- an analytic Jacobian that is subtly wrong still lets Newton limp to an answer. |
| **The limit is read off the POLARISATION CURVE** | not detected at a threshold. Walking `c_red(0)` down, `i` rises and **plateaus**. Three terminations, all the same physics: mediator starved (`c_red -> 1e-3`); `i` plateaus (`\|d ln i / d ln frac\| -> 0`); or Newton stops converging as `c_red -> 0`, which means the solution ceases to exist beyond `i_lim` -- **that crash IS the answer**, not a failure to work around. |
| **`i` DECREASING is flagged SUSPECT** | a turning point in a curve of this kind would be unphysical and is indistinguishable from the solver hopping solution families. Never harvested as `i_lim`. |
| **`branch_roughness`** | a polarisation curve should be SMOOTH. Worst jump in `d ln i / d ln frac` between consecutive points. Measured: 0.007-0.019 on clean cells, **0.170 on Br- ox x unstirred** -- which also sits below its own commuting bound. The curve flags the bad cell independently of its value. Previously only the endpoint of a curve nobody had plotted was ever inspected. |
| **No reduced-physics fallback** | `build_merged_matrix.py` substituted the Tier-0 value on convergence failure. It is now a **hard error that stops the build**. Confirmed firing. |
| **c-control accepted only above the commuting bound** | the homogeneous source can only ADD, so `i_ec < 0.9 i_t0` is not an answer however the walk ended. Without this, Br- ox x unstirred was accepted at 11.54 against its bound of 16.72 with the mediator still at 76% of bulk. |

### The physical result that came out of it — belongs in §S5.4

**Mediated systems where the mediator doubles as the supporting electrolyte have a different
limiting mechanism.** In Br- oxidation the mediator IS the supporting anion (0.25 M Br-);
Br- is negative and the electrode is an anode, so migration drives it TOWARD the surface faster
than reaction consumes it. `c_red(0)/c_bulk` sticks at 2.3e-2 while the SUBSTRATE is at 1e-20 --
the limit is substrate exhaustion behind a detached front, and the mediator can never be starved.
Terminating only on mediator collapse reports a LOWER BOUND for any migration-fed mediator, and
was **22% low** on that cell (84.8 against 108.3). Hofmann x unstirred shows the same signature
from the other side, with `c_red(0)` ABOVE bulk.

## 2. What changed in the code today, and why

### `julia/npp_ecprime.jl`

| change | reason |
|---|---|
| Newton-wall marker is **prefixed**, never overwritten | It used to be replaced by a *physical* limiter whenever the stalled state happened to satisfy the collapse test, so 14 of 48 rows read as converged when they were not — including by Fig. 4's envelope gate, which was validating an analytic envelope against lower bounds while reporting otherwise. |

| `newton_ec_ccontrol!` + `solve_ilim_ec_ccontrol` added | **The real fix.** The current ramp has a **fold** at the limiting current — `dc_surf/di → −∞`, so the Jacobian is singular exactly at the answer, and no mesh can cross it. Prescribing `c_red(0)` and solving for the current as an unknown (bordered system) has no fold. |
| c-control stepping made **adaptive** in `ln(frac)` | A fixed ladder left Br⁻-ox × flow stranded at `c_red/cb = 0.0955` purely because the next rung was too far. |

| both Newton acceptances now enforce the declared `tol` | See §1. The same loose fallback had been copied into `newton_ec_ccontrol!` when it was written. |

## 7. Two mistakes worth not repeating

1. **Chasing the mesh when the parameterisation was the problem.** Eleven mesh variants of the
   Hofmann cell were run before the fold was identified. A fold in the *continuation parameter*
   cannot be fixed by refining *space*. The tell was there early: every variant died at a
   different value but the same place in the ramp.
2. **Reporting a result before verifying the whole path.** "All 48 cells now reach collapse" was
   stated from a probe that anchored at the *stirred* cell; the production path anchors at the
   ramp's last safe state, which for the dead cell **is** the dead solve. The probe never tested
   the path production would take. Also: `i_subcap` was used as a physicality test in Round 1 —
   it is **not a bound** (the front detaches), and that error caused a correct finding to be
   rejected. The one rigorous relation is `i_ec ≥ i_t0`, the commuting bound.
